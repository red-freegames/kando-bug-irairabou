# 感度バグりイライラ棒

指を1ミリ動かすと、玉はワープする。

スマホ向けのイライラ棒ゲーム。画面のどこをなぞっても玉が「指の移動量 × 感度」だけ動き、電流の壁に触れたら感電してスタートへ戻ります。ステージが進むごとに感度が上がります。

| STAGE | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8〜 |
|---|---|---|---|---|---|---|---|---|
| 感度 | ×2 | ×3 | ×5 | ×8 | ×12 | ×20 | ×50 | ×100 |

## 遊ぶ

GitHub Pages で公開しています。スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように全画面で遊べます。PC ではマウスのドラッグで操作できます。

## 構成

- `index.html` — ゲーム本体（HTML / CSS / JS をすべて内包。外部ライブラリなし）
- `manifest.webmanifest`, `icon-*.png` — ホーム画面追加用
